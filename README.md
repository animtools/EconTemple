# EconTemple（エコンテンプレ）

> Conte Panel Extraction Tool for Animation Production Workflow  
> コンテ（絵コンテ）画像からパネルを自動抽出し、CLIP STUDIO PAINT 用 XDTS 出力まで対応する Windows 用デスクトップアプリです。

---

## このアプリが解決すること

コンテのパネルを手作業で切り出したり、タイムシートを一から書いたりしていませんか？  
EconTemple は、コンテ画像からパネルを自動検出・抽出し、カット割り当てや XDTS 出力まで一貫してサポートします。

---

## 主な機能

| 機能 | 説明 |
|------|------|
| **パネル自動抽出** | コンテページから個別パネルを自動で切り出し |
| **バッチ処理** | 複数ページの一括処理に対応 |
| **カスタム抽出** | ページごとに異なるパネル設定が可能 |
| **カット管理** | パネルをカットに割り当て、タイムライン管理 |
| **パネルリンク** | 関連するパネル間のリンク作成 |
| **XDTS出力** | CLIP STUDIO PAINT 用のタイムシート生成 |
| **グループ管理** | 複数のコンテページをグループ化 |
| **プロジェクト保存** | 作業状態を保存・復元 |

---

## システム要件

- **OS**: Windows 10 / 11（64-bit）
- **メモリ**: 4GB以上推奨
- **ディスク**: 100MB以上の空き容量

---

## ダウンロード

[Releases](https://github.com/Shinosuke/EconTemple/releases) から最新の **EconTemple-vX.Y.Z-win64.zip** を取得し、解凍して付属の `EconTemple.exe` を起動してください。

**VirusTotal スキャン結果**: 各 [リリースページ](https://github.com/Shinosuke/EconTemple/releases) の説明欄に掲載しています。

---

## 使い方（最短）

1. 上記から zip をダウンロードして解凍
2. `EconTemple.exe` をダブルクリックして起動
3. コンテ画像（PDF や画像）を開き、パネル抽出・カット割り当て・XDTS 出力を実行

詳細は [QUICKSTART.md](./QUICKSTART.md) を参照してください。

---

## 特長

### インストール不要・ポータブル

zip を解凍して exe を起動するだけ。レジストリ変更なし。フォルダごと別の PC に移してもそのまま動作します。

### データはローカル

プロジェクトや設定はローカルに保存されます。クラウド不要・個人情報の送信なし。
