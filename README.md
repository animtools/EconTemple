# EconTemple（エコンテンプレ）

> Conte Panel Extraction Tool for Animation Production Workflow  
> コンテ（絵コンテ）画像からパネルを切り出し、CLIP STUDIO PAINT 用 XDTS 出力まで対応する Windows 用デスクトップアプリです。

---

## 対象ユーザー

このアプリは以下の方々を対象としています：

- **制作進行**: デジタル作画アニメーターに配布する作画ファイル準備を効率化
- **デジタル作画アニメーター**: 受け取ったコンテを読み込み作画ファイルを効率的に準備

## 目的

制作進行の手間を減らし、アニメーターがすぐに作画を始められる環境を作ることを目指しています。

**主な利点**:

- コンテの手動切り出し作業を効率化
- カット情報（尺・セリフ・カメラワーク）のセットも可能
- クリップスタジオへのスムーズな連携
‐ 簡易的な書き込み機能搭載で作打ちのメモもこのアプリ内で完結

---

## このアプリが解決すること

コンテのパネルを一つ一つ切り出したり、タイムシートを一から設定していませんか？これらの作業はデジタル作画をする際には避けて通れない準備ですが、大量のカットを扱うとなるとなかなか骨の折れる作業です。
このアプリは、コンテ画像からカットごとのパネルを一括抽出し、尺やセリフ情報をセットした XDTS ファイルの出力まで一貫してサポートし、アニメーターや制作進行が作画ファイルを準備する負担を大幅に軽減します。

---

## 主な機能


| 機能               | 説明                                      |
| ---------------- | --------------------------------------- |
| **パネル一括抽出**      | コンテページから個別パネルを一括で切り出し                   |
| **バッチ処理**        | 複数ページの一括処理に対応                           |
| **カスタム抽出**       | ページごとに異なるパネル設定が可能                       |
| **ページ描画** | コンテページ上での描画・注記（作打ちメモに相当）                |
| **カット管理**        | パネルをカットに割り当て、コンテの尺情報をカットに紐づけ                   |
| **兼用カットの管理**     | 兼用カットの設定・書き出し |
| **XDTS出力**       | CLIP STUDIO PAINT 用のタイムシートファイルを生成して書き出し            |
| **グループ管理**       | 複数のコンテページをグループ化                         |
| **プロジェクト保存**     | 作業状態を保存・復元                              |


用語の詳細は [QuickStart.md](./QuickStart.md) の用語セクションを参照してください。

## システム要件

- **OS**: Windows 10 / 11（64-bit）
- **メモリ**: 4GB以上推奨
- **ディスク**: 100MB以上の空き容量

---

## ダウンロード

[Releases](https://github.com/Shinosuke/EconTemple/releases) から最新の **EconTemple-vX.Y.Z-win64.zip** を取得し、解凍して付属の `EconTemple.exe` を起動してください。

**VirusTotal スキャン結果**: 各 [リリースページ](https://github.com/Shinosuke/EconTemple/releases) の説明欄に掲載しています。

---

## 使い方（最短）

1. 上記から zip をダウンロードして解凍
2. `EconTemple.exe` をダブルクリックして起動
3. コンテ画像（PDF読込またはフォルダで指定）を開き、パネル設定・カット割り当て・XDTS 出力を実行

詳細は [QuickStart.md](./QuickStart.md) を参照してください。

---

## 特長

### インストール不要・ポータブル

zip を解凍して exe を起動するだけ。レジストリ変更なし。フォルダごと別の PC に移してもそのまま動作します。

### データはローカル

プロジェクトや設定はローカルに保存されます。クラウド不要・個人情報の送信なし。
